Every call to `animate()` or `timeline()` returns an `AnimationControls` object. This object lets you imperatively drive an animation after it has started — pausing mid-flight, jumping to a specific time, changing playback speed, or waiting for the animation to finish before running the next piece of logic.

## Getting an AnimationControls object

```javascript
import { animate } from "motion"

const animation = animate("#box", { opacity: 0 }, { duration: 1 })
```

The returned `animation` object is an `AnimationControls` instance. It proxies over every underlying browser `Animation` object that was created — one per animated property per element — so a single method call (e.g. `animation.pause()`) affects all of them at once.

## Methods

### `play()`

Resumes a paused animation from its current position.

```javascript
const animation = animate("#box", { x: 100 }, { autoplay: false })

// Start the animation manually at some later point
animation.play()
```

### `pause()`

Freezes the animation at its current position without resetting or committing styles.

```javascript
const animation = animate("#box", { x: 100 }, { duration: 2 })

setTimeout(() => {
  animation.pause()
  console.log("Paused at", animation.currentTime, "seconds")
}, 500)
```

### `stop()`

Stops the animation and sets the element's style to the current animated value. Unlike `cancel()`, `stop()` does not revert to the original pre-animation style — it leaves the element at wherever the animation was when `stop()` was called.

```javascript
const animation = animate("#box", { x: [0, 200] }, { duration: 2 })

setTimeout(() => {
  // Element stays at its current x position
  animation.stop()
}, 800)
```

### `finish()`

Immediately jumps to the end of the animation and commits the final keyframe value to the element's inline styles.

```javascript
const animation = animate("#box", { opacity: [1, 0] }, { duration: 2 })

// Skip to the end — element becomes opacity: 0 instantly
animation.finish()
```

### `cancel()`

Cancels the animation and reverts the element to its underlying (pre-animation) styles.

```javascript
const animation = animate("#box", { scale: 1.5 }, { duration: 0.5 })

// Something went wrong — undo the animation entirely
animation.cancel()
```

### `reverse()`

Reverses the direction of playback.

<Note>
  `reverse()` is currently marked **alpha** and is non-functional in this version of Motion One. Use `playbackRate = -1` to reverse an animation's playback direction at runtime instead.
</Note>

## Properties

### `finished`

<ParamField body="finished" type="Promise<any>">
  A `Promise` that resolves when all underlying animations have completed. Useful for sequencing logic after an animation ends.
</ParamField>

Awaiting `finished` is the cleanest way to chain animations without nesting callbacks:

```javascript
import { animate } from "motion"

async function sequence() {
  await animate("#step1", { opacity: [0, 1] }, { duration: 0.4 }).finished
  await animate("#step2", { y: [20, 0], opacity: [0, 1] }, { duration: 0.4 }).finished
  await animate("#step3", { scale: [0.9, 1] }, { duration: 0.3 }).finished

  console.log("All steps complete!")
}

sequence()
```

### `duration`

<ParamField body="duration" type="number">
  The total duration of the animation in **seconds**. This property is **read-only**. It is particularly useful when using physics-based easings (like `spring` or `glide`) whose durations are computed dynamically rather than set explicitly.
</ParamField>

```javascript
const animation = animate("#box", { x: 100 }, { easing: spring() })

// Duration is generated by the spring solver, not set by you
console.log("Spring will take", animation.duration, "seconds")
```

### `currentTime`

<ParamField body="currentTime" type="number | null">
  The current playback position of the animation in **seconds**. Both readable and writable — setting `currentTime` scrubs the animation to that point in time.
</ParamField>

Use `currentTime` to build scrubbers, progress bars, or scroll-linked animations when `scroll()` isn't available:

```javascript
const animation = animate(
  "#box",
  { x: [0, 300] },
  { duration: 2, autoplay: false }
)

// Wire a range input to scrub through the animation
const scrubber = document.querySelector("input[type=range]")
scrubber.addEventListener("input", () => {
  animation.currentTime = Number(scrubber.value) / 100 * animation.duration
})
```

### `playbackRate`

<ParamField body="playbackRate" type="number">
  The current playback speed multiplier. `1` is normal speed. `2` plays at double speed. `-1` plays in reverse. Readable and writable.
</ParamField>

```javascript
const animation = animate("#box", { rotate: 360 }, { duration: 4 })

// Double the speed mid-animation
setTimeout(() => {
  animation.playbackRate = 2
}, 1000)

// Play backwards
setTimeout(() => {
  animation.playbackRate = -1
}, 2000)
```

You can also slow-motion scrub using fractional values:

```javascript
// Slow-motion at 10% speed
animation.playbackRate = 0.1
```

### `playState`

<ParamField body="playState" type='"idle" | "running" | "paused" | "finished"'>
  A read-only string reflecting the current state of the animation. Maps directly to the browser's `AnimationPlayState`.

  - `"idle"` — The animation has not started or has been cancelled.
  - `"running"` — The animation is actively playing.
  - `"paused"` — The animation is suspended at a point in time.
  - `"finished"` — The animation has played to completion.
</ParamField>

```javascript
const animation = animate("#box", { opacity: 0 }, { duration: 1 })

animation.pause()
console.log(animation.playState) // "paused"

animation.play()
console.log(animation.playState) // "running"

await animation.finished
console.log(animation.playState) // "finished"
```

## Complete playback control example

The following pattern implements a play/pause toggle button with a real-time progress readout:

```javascript
import { animate } from "motion"

const animation = animate(
  "#spinner",
  { rotate: [0, 360] },
  { duration: 3, repeat: Infinity, easing: "linear" }
)

const toggleBtn = document.querySelector("#toggle")
const progressDisplay = document.querySelector("#progress")

toggleBtn.addEventListener("click", () => {
  if (animation.playState === "running") {
    animation.pause()
    toggleBtn.textContent = "Resume"
  } else {
    animation.play()
    toggleBtn.textContent = "Pause"
  }
})

// Show current time on every animation frame
function tick() {
  progressDisplay.textContent =
    `${(animation.currentTime ?? 0).toFixed(2)}s / ${animation.duration.toFixed(2)}s`
  requestAnimationFrame(tick)
}
tick()
```
