Motion One is a tiny, high-performance animation library built on the Web Animations API (WAAPI). It gives you a developer-friendly API for animating DOM elements, sequencing timelines, reacting to scroll, and applying physics-based spring and glide easing — all with minimal bundle overhead.

## Why Motion One?

Motion One is designed to stay out of your way. It wraps the browser's native Web Animations API with a clean, ergonomic interface — giving you hardware-accelerated performance by default, without a heavy runtime.

## Quick Example

```javascript
import { animate } from "motion"

animate("#box", { x: 100, opacity: 1 }, { duration: 0.5, easing: "ease-out" })
```

<Steps>
  <Step title="Install Motion One">
    ```bash
    npm install motion
    ```
  </Step>
  <Step title="Import and animate">
    Import `animate` from `"motion"` and pass it a selector, keyframes, and options.
    ```javascript
    import { animate } from "motion"

    animate(".card", { y: [20, 0], opacity: [0, 1] }, { duration: 0.4 })
    ```
  </Step>
  <Step title="Control playback">
    Every animation returns an `AnimationControls` object you can pause, reverse, or await.
    ```javascript
    const animation = animate(".card", { scale: 1.05 }, { duration: 0.3 })
    await animation.finished
    ```
  </Step>
</Steps>

<Note>
  Motion One is published as the `motion` package on npm and re-exports everything from `@motionone/dom`. The `motion` package is the recommended entry point for most projects.
</Note>
